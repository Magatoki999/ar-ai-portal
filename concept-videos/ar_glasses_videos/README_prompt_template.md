# ARスマートグラス コンセプト動画 — Nano Banana プロンプトテンプレート

ルキルキのARスマートグラス体験を、Gemini（Nano Banana画像生成 → Veo動画化）で
一貫したデザインのまま量産するためのテンプレート。実機が無い前提で、
コンセプト動画として「未来だけど日常」の質感を保つことを目的とする。

## 基本ルール

1. **必ず直前に確定した最良カットを画像1として渡す。** ゼロから毎回シーン全体を
   説明し直すと、Nano BananaがUIデザインを毎回微妙に再解釈してしまう
   （角丸の丸み・背景の不透明度・フォントがブレる）。
2. **「再現して」ではなく「そのまま同じ見た目で流用して」と指示する。**
   「デザインの再解釈・改善・スタイル変更は一切しないでください」という
   禁止形の一文を必ず入れる。これが無いと毎回少しずつ"良く"されてしまう。
3. **ARパネルのテキストは英語にする。** 日本語はレンダリングが崩れやすい
   （検証済み）。日本語UIにこだわる場合は、テキスト無しで背景・キャラクターを
   確定させてから、テキスト部分だけ別途合成する2段階を推奨。
4. **デザインが大きく崩れた場合は「編集モード」に切り替える。**
   場面全体を作り直すのではなく、既存カットをそのまま渡して
   「このパネルのテキストとアイコンだけ変更して、他は一切変えないで」と
   依頼する方が、UIの再現性は高い。

## ベーステンプレート

シーンごとに書き換えるのは **「シーン設定」** と **「AR表示の要素」** の
2ブロックだけ。それ以外の文言は固定で使い回す。

```
最初の画像のARパネルのデザイン（角丸の形、背景の透明度、フォント、
下部のシアンの線）を、新しく描き直すのではなく、そのまま同じ見た目で
別の内容に置き換えてください。デザインの再解釈・改善・スタイル変更は
一切しないでください。パネルの位置・サイズ・余白も画像1と同一にしてください。

シーン設定：
{ ここに場所・状況・一人称視点(POV)の説明 }

AR表示の要素：
1. 視界の右上（画像1と同じ位置・同じ透明度のパネル）に、
   { アイコン内容 }＋「{ 英語テキストラベル }」というテキストラベルだけ
   画像1のテキストと置き換える
2. 中央にルキルキが小さく浮かび、{ 表情・ジェスチャーの説明 }
   （画像1のルキルキと同じ画風・同じ発光の質感）

背景は実写でリアルなトーン、{ 光・時間帯の説明 }。
```

## 今後シーンを追加する時のチェックリスト

- [ ] 画像1は必ず「今までで一番デザインが崩れていない確定カット」を使う
- [ ] 「そのまま同じ見た目で」「再解釈・改善・スタイル変更は一切しないでください」を必ず入れる
- [ ] テキストラベルは英語にする（日本語UIが必要なら後工程で合成）
- [ ] 崩れたら方法A（禁止形の指示強化）→ それでもダメなら方法B（編集モード）の順で試す
- [ ] 生成後は動画からフレームを抽出して、既存シーンと並べてデザインのブレを確認する
