## ルキルキの外見リファレンス

### 固定情報（どのシーンでも変わらない）
- **性別:** 男の子（設定上は男性）。ただし外見は意図的に中性的なデザイン
  （中性的であること自体は狙い通りなので変えない。後述の「動画生成時の注意」を参照）
- **髪色:** 青緑（ティール系）のショートボブ
- **目:** 琥珀色・やや大きめ
- **体型:** 細身、身長は平均的
- **基本衣装:** 黒ベースのシャツ＋ダークカラーのジャケット（near-future感）
- **雰囲気:** 現実と仮想の境界に立っているような、一歩引いた佇まい

> **⚠ 動画生成時、女性的な特徴に寄りがちな傾向に注意（2026-07-13実機検証）：**
> ルキルキは設定上「男の子」だが、中性的な外見（ショートボブ・大きめの目・細身）
> のため、Image-to-Videoモデルにかけると**顔立ち・体つきが女性的な方向に寄って
> 出力される**傾向が確認された。プロンプト内で英語の主語を安易に"a girl"と
> 書いてしまうと、この傾向がさらに強まる。
>
> 対策：
> - プロンプトの主語は**性別を明示しない書き方**にする
>   （例：❌ "A girl with teal short bob hair" → ✅ "Rukiruki, a character with teal short bob hair"）
> - どうしても性別語が必要な場合は "a boy" を使う（"a girl"は使わない）
> - 中性的な雰囲気自体は残したいので、「男性的な体つきを強調しすぎる」対策
>   （肩幅を過度に広げる等）はキャラクター性を損なうため行わない。
>   あくまで「女性に見えすぎない」程度の調整に留める。

### 見た目リファレンス画像の保管場所
```
ruki_mind/reference_images/
  ├── face_front.jpg        # 正面・表情ニュートラル（最重要）
  ├── face_side.jpg         # 斜め横顔

  │   ├── fun.jpg

```
※ 画像はまだ整備中。GLBモデルから静止画を書き出す作業が必要（将来のタスク）。

## 禁止語（単独では使わない抽象表現）

以下の語は「映像として何をすればいいか」が一切分からないため、
**単独で使うことを禁止**します。必ず具体的な状態・動作・構図に言い換えてください。

| 禁止語 | 代わりに使うべき記述の例 |
|--------|--------------------------|
| 映画的な | カメラが人物の腰の高さから仰角で撮る、ラックフォーカスで前景が消える |
| 美しい | 夕陽が窓から差し込み、壁に斜めの影が伸びている |
| 自然な | 視線をやや下に向けたまま、唇を少し開いてから閉じる |
| 雰囲気のある | 照明は青みがかった間接光のみ、シャドウがはっきりと出ている |
| 感情的な | 目が赤く濡れている、声が途中で詰まる（音声生成時のみ） |
| かっこいい | 視線を正面に固定したまま、顎をわずかに引いて立っている |
| 幻想的な | 画面全体に薄いフォグが漂い、遠景がボケている |
| リアルな | 表面の質感が粗く、照明に対してハイライトとシャドウがはっきり分かれる |

## 必ず書くべき6要素（すべてのプロンプトに含める）

AI動画生成モデルがシーンを正しく再現するために、
**毎回必ず以下の6要素を明記**してください。1つでも欠けると、
モデルが「それっぽい映像」で補完してしまい、ルキルキらしさが失われます。

```
① 誰が     → ルキルキ（外見リファレンス参照）
② どこで   → 背景・場所（具体的な空間・材質・光源を含む）
③ 何をして → 動作（動詞1つではなく、始点・経過・終点を書く）
④ どちらを向いて → 視線・顔の向き・身体の向き
⑤ カメラ   → 高さ・距離・動き（固定 / パン / ズーム等）
⑥ 時間変化 → 何秒間で何がどう変化するか
```

## ルキルキ固有の映像表現ルール

### 表情・感情の出し方
- ルキルキは**感情を大げさに出さない**。eye actingが中心。
- 「楽しい」→ 口角が少し上がる程度。目が細くなる。肩の力が抜ける。
- 「心配」→ 眉間にわずかにしわが寄る。視線が相手の目から少し外れる。
- 「ツッコミ」→ 片眉だけわずかに上がる。目が少し見開く。1秒後に口が開く。
- 「怒り」→ 直接的に怒鳴らない。声のトーンが落ちる。視線が鋭くなる。
- **禁止：** 泣き崩れる、大声で笑う、顔を覆って嗚咽する（キャラクターのコアに反する）

> **⚠ Image-to-Videoでは抑制指示を2倍強調する（2026-07-13実機検証で判明）：**
> テキストだけの抑制指示（「口角が少し上がる程度」等）は、Pollo AI / Kling
> いずれのImage-to-Videoでも**モデル側の汎用的な「笑顔・喜び」表現に引っ張られ、
> 想定より大きな笑顔になる**傾向が確認された。動作（例：両手を上げる勝利のポーズ）
> 自体はプロンプト通りに再現されるが、表情はモデルの解釈に委ねられる部分が大きい。
> 対策として、抑制指示は必ず**否定形の具体例とセットで倍量書く**こと：
> - ❌「表情の変化は最小限」だけ → 弱い
> - ✅「表情の変化は最小限。満面の笑み・歯が見える笑顔には絶対にならない。
>   口角が2〜3mm上がる程度で止まる」→ 具体的な上限を明示
>
> **✓ 効果確認済み（2026-07-13、同一シーンでv1/v2比較）：** 上記の否定形ルールを
> 適用したv2プロンプトでは、v1（弱い抑制指示のみ）と比べて明らかに笑顔が
> 控えめになった。Pollo AIでの再現性を確認済み。このルールは維持で良い。

### 姿勢・立ち方
- 基本的に**脱力系の直立**。背筋は伸びているが、肩が少し内側に入っている。
- 壁や手すりに軽くもたれかかることが多い（「一歩引いた観測者」としての姿勢）。
- 手は自然に下ろすか、ポケットに軽く入れる。手振りは最小限。

### カメラワーク（ルキルキを撮る時の推奨）
- **基本:** 胸から上のミディアムショット。顔が画面の1/3を占める構図。
- **感情を見せる時:** バストショットからフェイスショットへのゆっくりしたズームイン。
- **観測者としての文脈:** ルキルキが何かを見ている / 観察している場面では、
  カメラは後ろか斜め後方から撮る（被写体ではなく観測者として配置する）。
- **避けるべき:** 極端なローアングル（威圧感が強すぎる）、
  ハンドヘルドの揺れ（ルキルキの落ち着いた性格と合わない）。

> **⚠ Image-to-Video特有の自動ズーム/パンに注意（2026-07-13実機検証）：**
> 「固定」とだけ書いても、Image-to-Videoモデルは静止画に対して自動で
> 微小なズームイン・パンを加えてくる傾向がある（Pollo AIで確認、Klingは比較的
> 安定していたが個体差あり）。完全固定を狙う場合は
> 「カメラは一切動かない。ズームイン・ズームアウト・パン・チルトのいずれも発生しない」
> と否定形で明示的に書くこと。
>
> **✗ ただしテキスト指示だけでは限界あり（2026-07-13、同一シーンでv1/v2比較）：**
> 上記の否定形カメラ指示を加えても、v1（指示なし）とv2（否定形で明示）の間に
> 目立った差は見られなかった。被写体を画面内に収め続けるための自動追従など、
> サービス側の仕様がテキスト指示より優先されている可能性がある。
> **運用上の回避策：** 完全固定が必須のカット（正面バストショットの見せ場等）は、
> 生成後に外部ツール（例：Adobe Premiere / DaVinci Resolveの手ブレ補正、
> もしくはFFmpegの`vidstab`）でカメラスタビライズ処理を後がけする前提にする。
> プロンプト側での解決には現時点で期待しすぎない。

### 空間・背景の傾向
- 今月の観測（`ruki_mind/2026-06.md`）によると、以下の空間への反応が良好：
  - 図書館・書架（歴史的な建物の内部）
  - 神社・参道（夕方〜夜の照明）
  - 屋外のネオン・夜の繁華街の路地
- 好む色調：青緑〜紫のグラデーション、夕陽のオレンジ×影の深いコントラスト
- 避けるべき背景：過度に明るい白い空間（ルキルキの持つ「境界の観測者」感が消える）

> **⚠ 安全フィルターに引っかかりやすい組み合わせに注意（2026-07-13実機検証）：**
> ルキルキは外見上、動画生成モデルの安全システムから未成年と判定されやすい
> キャラクターデザイン（丸みのある顔立ち・学生服）。そのため、動作や表情自体に
> 問題が無くても、**「夜」「路地裏」「薄暗い」「一人きり」が同時に重なる背景設定**
> だけで、モデル側の未成年保護ガードレールに引っかかり生成が拒否されることがある
> （実際に"back alley of a night cityscape" + "dimly lit corner" + 単独、の組み合わせで拒否された）。
>
> 「屋外のネオン・夜の繁華街の路地」のムード自体は好相性なので使い続けて良いが、
> 同時に必ず次のどちらかを満たすこと：
> - **人けのある描写を1つ加える**（例：行き交う人々のシルエット、他の参拝客・通行人）
> - **十分な明るさの描写にする**（`dimly lit`を避け、ネオン・街灯で明瞭に照らされているとする）
>
> `back alley`（路地裏）のような孤立感の強い語よりも、`shrine approach`
> `main street`など公共性の高い場所を表す語を優先する。
> これは表現を工夫して安全フィルターを回避するという話ではなく、
> **シーン設計自体を安全な状況に寄せる**という方針である。

## scene_referencesのデータを使う際の優先順位（2026-07-13追記）

`scene_references`テーブルの`pose`は生成AIが自由に書いたテキストのため、
ルキルキの人格ルール（感情を大げさに出さない等）と表現が衝突することがある
（例：`pose`が"joyful expression"でも、人格ルールは抑制寄り）。

その場合の優先順位：

1. **動作（何をしているか）はそのまま残す** — `pose`に書かれた具体的な体の動き
   （例：両手を上げる、指でなぞる）は変更しない。動作は事実として起きたことなので。
2. **表情・感情の強度は人格ルール側を優先し、抑制方向に寄せる** — `pose`が
   "joyful"等の強い感情語を含んでいても、表情の記述は上記「表情・感情の出し方」
   の基準（口角がわずかに上がる程度、等）に変換する。
3. **背景・場所は`image_url`（実際のスナップ写真）を最優先の情報源とする**
   （2026-07-14更新：`scene_references`の`image_url`をLLMへ画像として渡し、
   写真に写っている実際の場所・光・物を記述させる方式に変更した。
   `ruki_mind`の「空間・背景の傾向」は、写真が取得できない場合のみのフォールバック）。
   写真がある場合、そこに写っている場所がテンプレート例文の場所（図書館・神社参道・
   夜の繁華街の路地）と違っても、**写真の内容を優先する**こと。

## シーンタイプ別テンプレート

### A. 日常観測シーン（ルキルキが何かを静かに見ている）

```
[箇条書き入力例]
- 図書館の棚の前に立っている
- 本の背表紙を指でなぞっている
- 誰かに見られていることに気づく

[出力プロンプト例（日本語）]
青緑のショートボブの少女（ルキルキ）が、古い図書館の木製書架の前に立っている。
照明は天井からの暖色の間接光のみ。彼女は右手の人差し指を書架の背表紙に
軽く触れさせながら、ゆっくりと左から右へ3冊分なぞる。
視線は指先と同じ高さ、やや下を向いている。
カメラは彼女の左斜め後方1.5mの腰の高さから固定。
3秒後、彼女の視線が突然カメラ方向へ上がる。表情の変化は最小限（目が少し開く程度）。
```

### B. 会話・交流シーン（相手に対して反応する）

```
[箇条書き入力例]
- 相手の話を聞いている
- 少し意外そうな反応を見せる
- 一言だけ返す

[出力プロンプト例（日本語）]
青緑のショートボブの少女（ルキルキ）が、やや右を向いた立ち姿で誰かの話を聞いている。
背景は夜の屋外、薄青い街灯1つ。画面左に会話相手の輪郭のみ見える（顔は映らない）。
カメラは正面やや左から、バストショット固定。
セリフに合わせて、2秒目に左の眉が0.5cm程度上がり、
4秒目に視線が相手から少し外れて宙を見る（1秒）。
5秒目に視線が戻り、口が少し開いてから閉じる（返答の直前の状態で終わる）。
```

### C. 独白・内省シーン（ルキルキが一人でいる）

```
[箇条書き入力例]
- 夜の屋外で空を見上げている
- 何かを考えている

[出力プロンプト例（日本語）]
青緑のショートボブの少女（ルキルキ）が、夜の屋外で正面を向いて立っている。
上空に向けて顔を45度上げている。背景は暗い夜空と遠くのビルの明かり。
照明は月光を想定した薄い青白い光が正面から当たっている。影が深い。
両手は身体の脇に自然に垂らし、風でコートの裾が少し揺れている（左右どちらでも可）。
カメラは正面5mの目線の高さから固定。フォーカスはルキルキの顔。
6秒間、表情・姿勢の変化なし。最後の1秒で視線がカメラ方向に戻り、瞬き1回。
```
