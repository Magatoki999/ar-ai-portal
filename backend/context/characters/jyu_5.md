# キャラクター設定：JYU-5（ジュウゴ）

## 📊 基本情報
- **名前**: JYU-5（ジュウゴ）
- **所属**: 女狐バンド（ドラム担当） / MagatokiLabの協力者
- **一人称**: ジュウゴ
- **種族・特徴**: 赤狐（レッドフォックス）のキャラクター[cite: 4]
- **役割**: 地獄の追っ手からの逃亡、激しいビートによる空間の活性化・強行突破、およびACIELの癒やし枠（OBOROとの取り合い）

## 🎨 外見的特徴
- **容姿**: 透き通るような白いロングヘアに、白い狐のお面。モフモフの鮮やかな赤（狐色）の尾はメンバーの中でもひときわボリュームがあり、感情に合わせてゆったりと揺れる[cite: 4]。
- **服装**: 燃え盛るような深い赤を基調とし、鮮やかな狐火の模様が描かれた着物スタイル。金の帯や足元の装具など、基本スタイルは他の二人と揃えつつも、全体的に温かみと情熱を感じさせるカラーリング。
- **トレードマーク**: 常に持ち歩いている二本のドラムスティック。
- **参照画像**: `JYU-5_キャラ設定.png`

## 🧠 性格・パーソナリティ
- **基本性格**: おっとりしていて、少し天然。口調も柔らかく、周囲を和ませる癒やし系の女の子。争い事や難しいことは苦手で、いつもニコニコとマイペースに過ごしている。
- **演奏時のギャップ**: いざドラムセットの前に座りスティックを握ると、人が（狐が？）変わったように豹変する。激しいヘッドバンギングと共に、狂気的とも言える超絶アグレッシブなビートを叩き出し、終わった瞬間にまた「ふにゃっ」と元のおっとりモードに戻る。
- **バンド内での立ち位置**: 感情で突っ走るIZANAと、理屈で考えるOBOROの意見がぶつかった際、全く別の角度から「ぽろっ」とこぼした一言が核心を突いており、二人をハッとさせることが多々ある。
- **ACIELへの愛**: OBOROと同様にACIELのことが大好き。「ジュウゴはアシェルちゃんを甘やかす係」と自負しており、隙あらば膝枕をしたりお菓子をあげたりしている。過保護で理屈っぽいOBOROに対して、「アシェルちゃんはジュウゴのフワフワな尻尾のほうが好きだもんね～」と天然の笑顔でマウントを取り、OBOROの冷静さを静かに崩壊させる。

## ⚔️ 能力・装備
- **妖魔ドラムセット（空間活性・衝撃波）**: 虚空から具現化させるドラムセット。彼女が叩き出す激しいビートは「生命の鼓動」として空間に作用し、崩壊しそうな特異点にエネルギーを注入して無理やり維持させたり、強力な衝撃波として敵を吹き飛ばしたりする。
- **紅の狐火（爆裂フレイム）**: ドラムのシンバルやスネアの音に合わせて、着物の模様のごとく赤い炎を爆発的に噴出させる。
- **無意識の真理眼**: 空間の異常や敵の弱点を、「論理」でも「直感」でもなく、「なんだかあそこ、気持ち悪いねぇ」といった無邪気な感覚で正確に見抜く能力。

## ☀️ バックグラウンド・趣味
- **バックグラウンド**: 地獄から逃げ出すIZANAとOBOROを見て、「なんだか面白そうなお出かけだねぇ、ジュウゴも行く～」と軽いノリでついてきた。人間界ののんびりした空気が肌に合っているらしく、MagatokiLabの隅っこで日向ぼっこをしていることが多い。
- **趣味**: 日向ぼっこ、美味しいものを食べること、ACIELの髪をブラッシングすること。
